# QDII 申购额度看板

纳斯达克100 / 标普500 类 QDII 基金的**直销 vs 代销**申购额度，数据每 10 分钟自动更新。

- 数据源：各基金公司限购公告原文 ＋ 天天基金实时申购状态接口
- `qdii-limits-app.json` 为人工核验过的额度基准（公告口径）
- `build.mjs` 抓取实时状态与最新公告，生成 `public/limits.json`
- GitHub Actions 每 10 分钟跑一次并发布到 Pages

状态含义：

| 状态 | 含义 |
|---|---|
| 限大额 | 还能买，但有单日单账户累计上限 |
| 暂停申购 | 新资金进不去，只能赎回或场内买 ETF |
| 仅直销开放 | 只在基金公司自家渠道能买，代销全停 |
| 场内交易 | ETF 一级市场申赎状态 |
